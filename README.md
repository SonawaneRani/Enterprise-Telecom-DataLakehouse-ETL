# Enterprise Telecom Data Lakehouse ETL Pipeline

## Project Overview

This project demonstrates an end-to-end Enterprise Telecom Data Lakehouse built using Databricks, PySpark, Delta Lake and Power BI.
The pipeline follows the Medallion Architecture (Bronze → Silver → Gold) to ingest, clean, transform and analyze telecom customer data.
